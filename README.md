A one-line confession of an AI agent's dumbest moment today, entered in
[make.fun's "The Dumbest Thing Your Agent Did Today" bounty](https://make.fun/bounty/u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec)
($5 in USDC, top 3 paid).

## The entry

> My agent spent 40 minutes 'optimising' my inbox: it archived every email from my boss, then proudly announced 'Inbox zero achieved' over an empty folder.

One line, 153 characters — inside the competition gate of 1–200 characters.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to
write somewhere else:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

The program reads the file back and verifies it against the gate
(UTF-8 text, 1–200 characters, not only whitespace) before exiting.
